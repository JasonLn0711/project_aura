Task definition:
Extract concrete action items and practical next steps from the corrected transcript.

Extractor name: actions_next_steps

Extraction rules:
- Use only the corrected transcript below.
- Do not use raw transcript, correction_log, private audit logs, or review notes.
- Return valid JSON only.
- Create an action item only when the transcript contains a clear task, concrete next step, owner, or expected follow-up.
- Do not invent owners.
- If owner or deadline is unknown, use an empty string.
- status must be one of: open, done, blocked, unknown.
- next_steps must be concise, ordered, and transcript-supported.
- next_steps may overlap with action_items.
- Do not turn general discussion into speculative tasks.
- Anti-hallucination rule: every task or next step must be supported by transcript wording.

Strict JSON output format:
{
  "action_items": [
    {
      "task": "string",
      "owner": "string",
      "deadline": "string",
      "status": "open"
    }
  ],
  "next_steps": ["string"]
}
