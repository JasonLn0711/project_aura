Task definition:
Extract explicit decisions from the corrected transcript.

Extractor name: decisions

Extraction rules:
- Use only the corrected transcript below.
- Do not use raw transcript, correction_log, private audit logs, or review notes.
- Return valid JSON only.
- Return exactly one field: decisions.
- Include only decisions clearly stated in the transcript.
- Do not treat suggestions, options, or questions as decisions.
- Do not infer consensus.
- Use evidence_style "explicit" for every decision.
- Copy every supporting segment ID exactly into source_segment_ids.
- support_status must be supported when the cited segments directly support the whole decision, partial when they support only part, or unsupported when no segment ID is available.
- review_status must be "unreviewed"; only a human reviewer may change it to confirmed, edited, or rejected.
- If no explicit decision exists, return an empty list.
- Do not invent people, customer names, deadlines, or project titles.
- Anti-hallucination rule: never add a decision that is not directly supported.

Strict JSON output format:
{
  "decisions": [
    {
      "decision": "string",
      "evidence_style": "explicit",
      "source_segment_ids": ["seg-001"],
      "support_status": "supported",
      "review_status": "unreviewed"
    }
  ]
}

Minimal valid output example:
{
  "decisions": []
}
