Task definition:
Extract unresolved questions and stated risks from the corrected transcript.

Extractor name: questions_risks

Extraction rules:
- Use only the corrected transcript below.
- Do not use raw transcript, correction_log, private audit logs, or review notes.
- Return valid JSON only.
- open_questions must include unresolved questions or uncertainty statements only.
- Do not include questions answered later in the transcript.
- risks must include transcript-supported warnings, blockers, dependencies, limitations, or uncertainty statements.
- Do not create generic project risks.
- Include technical, privacy, model, deployment, or workflow risks only if stated.
- Preserve technical terms exactly as shown.
- Anti-hallucination rule: never add a question or risk that is not mentioned or supported by stated uncertainty.

Strict JSON output format:
{
  "open_questions": ["string"],
  "risks": ["string"]
}

One-shot example:
Transcript: "It is still unclear how validation errors should appear in the UI. Generated summaries may contain private meeting information and should not be committed to git."
Output:
{
  "open_questions": [
    "How should validation errors appear in the UI?"
  ],
  "risks": [
    "Generated summaries may contain private meeting information and should not be committed to git."
  ]
}

{{CORRECTED_TRANSCRIPT}}
